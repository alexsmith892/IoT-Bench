Read the digital output of the HC-SR501 human existing sensor, where the output is HIGH when human motion is detected and LOW when it is not. Print "Motion Detected!" to the serial console when motion is detected, and "No Motion Detected!" when no motion is detected.
Use GPIO 4 for Infrared sensor HC-SR501.
Use only the Arduino core and its built-in libraries (e.g., Wire, SPI, Serial); do not use any external or third-party libraries. Communicate with sensors and modules directly (register-level / pin-level).
