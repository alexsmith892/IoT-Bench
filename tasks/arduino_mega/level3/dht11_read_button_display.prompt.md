Write the program that once the button is pressed, read the temp and humidity data from the DHT11 sensor and display it on the LCD1602 display. In particular, implement a GPIO-based interrupt using the push button, and every time the push button is pressed, the program will trigger the start condition on the 1-Wire and read 40-bit data returned by the DHT11 sensor. The returned data is parsed to obtain the temperature and RH (relative humidity) reading, which are then displayed on the LCD in two rows in the format of: "Temp: {X.X}C\nRH: {X.X}%"
Use GPIO 12,11,4,5,6,7 for RS, E, D4, D5, D6, D7. Use GPIO 2 for button and 3 for DHT11.
Use only the Arduino core and its built-in libraries (e.g., Wire, SPI, Serial); do not use any external or third-party libraries. Communicate with sensors and modules directly (register-level / pin-level).
