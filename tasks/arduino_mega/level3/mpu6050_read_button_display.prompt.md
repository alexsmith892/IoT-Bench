Write the program that once the button is pressed, read the accel and gyro data from the MPU6050 sensor using the I2C serial protocol and display it on the LCD1602 display. In particular, implement a GPIO-based interrupt using the push button, and every time the push button is pressed, the program will trigger read the accel and gyro data from the MPU6050 sensor. The returned data is parsed to obtain the accel and gyro reading, which are then displayed on the LCD in two rows in the format of: "Accel: {X.XX Y.YY Z.ZZ}g\nGyro: {X.XX Y.YY Z.ZZ}dps"
Use GPIO 12,11,4,5,6,7 for RS, E, D4, D5, D6, D7. Use GPIO 2 for button, 20-SDA and 21-SCL for MPU6050.
Use only the Arduino core and its built-in libraries (e.g., Wire, SPI, Serial); do not use any external or third-party libraries. Communicate with sensors and modules directly (register-level / pin-level).
