Write the program that will read the password input from the 16 key keypad, there are in total 8 lines connected to each 4 rows and 4 cols. In particular, the password will be set to "1234". The program will read the key input from the 16 key keypad, and if the input matches the password, the program will connect the relay to unlock the safebox. The program will also display the input password on the LCD1602 display in the format of: "Input: {XXXX}\nStatus: Success/Fail"
16 Key keypad: use GPIO 22,24,26,28 for Rows and GPIO 30,32,34,36 for Columns. Relay: use GPIO 13. LCD1602: Use GPIO 12,11,4,5,6,7 for RS, E, D4, D5, D6, D7
