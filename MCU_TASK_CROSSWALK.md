# MCU Task Crosswalk

This document maps upstream `iot-skillsbench` tasks to the current IoT-Bench implementation. It is a documentation/audit artifact only; no README, task YAML, runner, validator, or circuit file was changed for this pass.

Local sources used: upstream clone `https://github.com/iot-agent/iot-skillsbench` at `tasks/level*/level*-*.txt`; local `tasks/<platform>/level*/*.yaml`; generated `cases/*`; Wokwi `diagram.json`; Renode `case.repl`; validators in task YAML; tracked evidence indexes in `docs/esp32s3_espidf-evidence.json` and `docs/zephyr_nano33ble-evidence.json`.

Status meanings: `live-verified BC` is tracked fresh evidence; `local-only BC artifact` is an ignored local `verification.json` and should not be treated as portable leaderboard proof; `scored-out` is implemented but excluded from canonical scoring for a documented simulator limitation; `addition` is local coverage outside upstream.

## Platform-Level Deviations

- Arduino Mega / Wokwi: upstream physical tasks are converted into Wokwi cases with VCD, serial, LCD bus, and variant-based validators. Analog tasks use deterministic Wokwi/surrogate values on AVR ADC scale. All 41 mapped cases have local BC artifacts in this checkout, but no tracked Arduino evidence index exists.
- ESP32-S3 ESP-IDF / Wokwi: upstream task intent is implemented as ESP-IDF CMake projects rather than Arduino sketches. The tracked evidence index reports 43/43 fresh BC. Known intentional deviations are documented in `docs/esp32s3-task-status.md`: DHT22-compatible DHT surrogate, DS1307 date/time-only RTC judgment, safebox keypad GPIO remaps, partial keypad switch surrogates, deterministic analog values, custom BME280/MPU6050 chips where needed, and digital over-temperature surrogate for DS18B20.
- Zephyr nRF52840 / Renode: upstream task intent is adapted to Zephyr/Nano 33 BLE with generated overlays and headless Renode `case.repl` circuits. The tracked evidence index reports 41/42 canonical fresh BC, one canonical scored-out task (`safebox_display`), and one non-canonical addition (`lsm9ds1_read_i2c`). Renode-specific deviations include custom SAADC and sensor models, stretched single-wire timing for DHT11/DS18B20, LCD validation by VCD bus decode, and temperature/humidity-only BME280 I2C coverage.
